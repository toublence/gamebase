# Legacy level data (rules "basic-1" / "switch-1", schema 1)

These 485 boards (campaign 100, switch 20, daily 365) belong to the original single-tile ruleset.
They are kept for reference and are **not** loaded by the current game, which uses rules
"arrow-path-2" (schema 2) from `game/data/v2/`. Their validation results apply only to the legacy
rules and are not counted as validation of the new game. Excluded from exports.
