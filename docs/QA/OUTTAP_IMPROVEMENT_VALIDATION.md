## A. 무엇을 바꿨나 (P1~P6)

### P1. 보드 카메라와 가독성

- **전체 보기 → 플레이 배율:** 모든 판은 전체 그림으로 시작합니다. 전체 보기 칸이 23px보다 작은 판은 잠깐 보여 준 뒤 칸 30px 배율로 0.6초에 걸쳐 다가갑니다.
  - 첫 HARD는 안내판 2초 + 전체 보기 1.2초 뒤에 다가갑니다.
  - 그 사이 판을 만지면 다가가지 않습니다.
  - 코드: `ArrowBoardView.overview_then_play()`, `play_zoom()`, `has_play_zoom()`.
- **카메라 버튼:** 오른쪽 아래 버튼이 "확대 ↔ 전체 보기"를 오가고, 아이콘이 다음 동작을 보여 줍니다(돋보기+ / 네 모서리).
- **확대·이동:**
  - 핀치(중심 이동 포함), 확대 중 한 손가락 드래그, 빈 곳 두 번 탭을 지원합니다.
  - 빠르게 놓으면 잠깐 미끄러지고 가장자리에서 멈춥니다.
  - 핀치 뒤 남은 손가락은 이동만 하고, 탭으로 처리되지 않습니다.
- **머리와 몸통:** 몸통은 70% 불투명도, 머리는 큰 삼각형(칸의 0.56×0.72)입니다. 머리 둘레를 판 색으로 얇게 오려 내 옆 선과 붙어 보이지 않게 했습니다(`ArrowStyle`).
- **터치 영역:** 반경 24px 기준으로 최대 2.2칸까지 넓혔습니다(이전 1.25칸).
- **애매한 터치는 무료:** 다음 경우에는 하트를 깎지 않고 두 화살표가 들썩입니다.
  - 두 화살표 거리 차가 화면 9px 미만일 때
  - 가장 가까운 화살표는 막혔는데 가까이에 빠질 수 있는 화살표가 있을 때
- **장애물 표시:** 막힌 화살표를 누르면 다음을 1초(첫 HARD 경고 때는 2.2초) 동안 표시합니다.
  - 길을 막은 화살표: 빨간 테두리
  - 머리에서 부딪히는 칸까지: 점선과 고리

### P3. HARD 실패와 재도전

- **첫 HARD 경고:** 시도마다 첫 막힌 탭 1회는 경고와 장애물 표시만 하고 하트를 깎지 않습니다(레벨 데이터 `grace=1`, 5스테이지만).
- **체크포인트:** 묶음이 있는 판(5~20)에서 화살표 절반을 빼는 순간 저장합니다.
  - 저장 내용: 이동 기록 + 판 상태 문자열.
  - 복구할 때 실제 규칙으로 다시 재생하고, 판이 정확히 같지 않으면 복구하지 않습니다.
  - 저장 파일에서도 이동 기록의 앞부분과 일치하고 같은 판을 만들 때만 유지합니다.
- **실패 카드:** 체크포인트부터 다시(무료, 시도당 1회) → 다시 시작(무료, 항상) → 광고 보고 하트 1개(준비됐을 때만) → 홈.
- **중복 지급 없음:** 보상은 클리어 때만 줍니다. 황금 화살표는 이동 기록으로 셉니다. 리그는 항목별 주 1회입니다. 실수 수는 복구해도 유지됩니다.
- **실패 후 전면 광고:** 실패 카드 직전 광고를 뺐습니다. 2026-10-11 사용자 결정으로, 실패 카드에서 "다시 시작"을 누를 때 제한 규칙(1~5 제외, 설치 후 3분, 직전 광고 후 2.5분, 실행당 4회) 안에서 전면 광고가 나오도록 다시 넣었습니다. 체크포인트 복구에는 나오지 않습니다.
- **홈 "재도전":** 실패한 저장 상태면 홈 버튼이 "재도전"이고, "하트를 모두 썼어요 · 다시 도전해요"라고 표시합니다.

### P5. 온보딩과 클리어 화면

- **첫 실행:** 이야기 카드 3장 없이 바로 1스테이지로 들어갑니다. 규칙은 1~4판 안내 문구로 배웁니다. 시작 이야기는 마을 화면의 "이야기 보기"에서 읽을 수 있습니다.
- **일반 클리어:** 별, 평가("Perfect!/Great!/Cleared!"), "스테이지 N 완료!", 새 장면(있을 때), 큰 "다음 스테이지", 홈만 남겼습니다. 출석(연속 등불) 카드, 리그 내역, 보물 복원, 기록 표, 다음 5판 경로는 뺐습니다.
- **도전 판 클리어:** 일반 클리어와 다르게 연출합니다.
  - "큰 판 클리어!" 리본
  - 금빛 물결과 두 배 색종이
  - 카메라가 전체 그림으로 물러남
  - 큰 팡파르
- 새 장식 시스템이나 재화는 추가하지 않았습니다.

### P6. 오디오·광고 유지

- **오디오:** 효과음·음성·BGM은 삭제하지 않았습니다. 이번 라운드에서 소리는 바꾸지 않았고 **청취 검증도 하지 않았습니다**.
- **광고 기능:** AdMob·UMP 코드는 그대로입니다. 디버그 빌드는 Google 공식 Android 테스트 ID를 씁니다. 운영 ID는 비어 있고, 임의로 만들지 않았습니다.
- **광고 실패 처리:** 광고가 준비되지 않아도 이어서 진행됩니다(`interstitial_opportunity`가 생략 이유와 함께 항상 다음 단계를 실행). 생략 이유는 원인별로 로그에 남습니다(`ad_skipped`: UNSUPPORTED_PLATFORM, CONSENT_NOT_READY, NO_FILL, LOAD_IN_PROGRESS 등).

- **홈:** "재도전"(049). 복구 뒤 정확히 27개 남은 판, 하트 3, 안내 문구(054). 다시 연 실패 카드 배치 정상(058, 수정 후).
- **클리어:** 카메라가 전체 그림으로 물러남 → "큰 판 클리어!" 리본, 별 3(068).
- **광고:** 실패 직후 광고 없이 실패 카드가 나옴(Mac은 광고 미지원이라 실제 광고 동작은 별도 확인 필요).

### 확대·축소와 선택

- **선택:** 확대 배율(칸 28~31px)에서는 판독이 맞은 탭이 다른 화살표로 잘못 판정된 경우를 관찰하지 못했습니다(탭 수는 따로 세지 않았습니다).
- **전체 보기(칸 14~17px)에서 애매한 판정이 잦음:** 선 위를 정확히 눌러도 0.6칸 안에 다른 화살표가 있으면 "애매함"으로 처리돼 아무 일도 일어나지 않았습니다. 하트는 지켜지지만, 사람이 들썩임을 못 보고 다음 탭으로 넘어가면 막힌 탭이 될 수 있습니다(4스테이지 1차 실패).
- **두 번 탭 / 카메라 버튼:** 카메라 버튼은 수정 뒤 자동 다가가기와 같은 배율이 됐습니다(061). 두 번 탭은 자동 테스트로만 확인했습니다.
- **드래그 이동:** 확인했습니다. 빠른 드래그 뒤 미끄러짐, 가장자리 멈춤도 확인했습니다. 드래그가 화살표 탭으로 처리되지 않았습니다(091).
- **핀치:** 마우스로는 두 손가락을 넣을 수 없어 **미검증**입니다(Android 필요).

## D. 기존 보고서와 비교

### 첫 HARD의 가독성 개선 여부 — 개선됨

| | 이전 | 이후 |
|---|---|---|
| 판 / 화살표 | 29×36 / 93 | 20×25 / 55 |
| 화면 전체 보기 칸 | 15px | 약 21px |
| 머리·몸통 | 단색 가는 선, 작은 머리 | 큰 머리 + 판 색 테두리, 몸통 70% |
| 시작 카메라 | 확대된 가운데로 시작(전체 모름) | 전체 보기 → 확대(돌아오기 버튼) |
| 막힌 이유 | 짧은 깜빡임 | 막은 화살표·점선·고리 1~2.2초 |

전체 보기만으로도 사과 모양과 화살표 방향이 읽혔고, 1.44× 확대에서는 머리가 분명했습니다.

남은 한계: 1차 시도에서 판독 때문에 잃은 하트 4개(서로 다른 판독 실수 3건과 그 결과로 막힌 탭 1번)는 모두 머리 앞 레이가 몇 칸 떨어진 다른 화살표 칸에 걸리는 것을 놓친 경우였습니다(꺾인 긴 화살표의 먼 구간, 작은 L자 화살표, 다른 화살표의 머리 칸). 점선 표시 덕분에 매번 원인은 바로 알 수 있었고, 그 판독 자체가 이 퍼즐의 재미 요소이기도 합니다.

### 실패와 재도전 부담 개선 여부 — 개선됨

- **실패 직후:** 광고 없이 선택지가 바로 나옵니다.
- **체크포인트:** 절반(27개 남음) 지점부터 하트 3개로 다시 할 수 있어, 처음부터 55개를 다시 지우지 않아도 됩니다. 이전 감사의 "34개 지우고 실패 → 처음부터"와 비교하면 부담이 절반 이하입니다.
- **첫 막힘 경고:** 규칙을 다시 알려 주는 무료 실수 1회가 첫 실패를 늦춥니다.
- **홈 문구:** "재도전"이 실제 상태와 맞습니다.

남은 점: 체크포인트는 시도당 1회입니다. 두 번째 실패에서는 처음부터(또는 광고 이어하기)여서, 이번처럼 체크포인트 뒤에 또 실패하면 부담이 다시 큽니다.

### 난이도가 재미있는 도전으로 느껴지는가 — 대체로 그렇다 (Claude 주관)

- **5스테이지:** 시작 출구가 3개뿐이라 "어디부터?"를 찾는 순간이 있습니다. 한 화살표를 빼면 2개 이상 길이 열리는 순간이 15번 있어 연쇄가 시원했습니다. 두 번째 시도는 실수 없이 끝났고, 성취감이 있었습니다.
- **6 쉬어가기:** 처음 출구가 6개이고 전체 보기에서도 읽혀 확실히 가벼웠습니다(2차 약 75초).
- **10:** 처음 15개는 막힘 없이 진행됐지만, 판이 커서 전체 보기만으로는 읽을 수 없고 확대·이동이 필요합니다.
- **20:** 전체 보기에서 머리가 보이지 않고, 확대하면 판의 약 40%만 보여 이동이 많습니다. 마지막 판으로서 도전감은 있겠지만 피로도는 사람 테스트로 확인해야 합니다.

### 사용자 관점 판단 — KEEP (조건부)

"내가 실제 사용자라면 Outtap을 KEEP하겠다. 첫 HARD에서 막힌 이유가 바로 보이고 절반에서 다시 할 수 있어서, 실패가 '다시 지우는 노동'이 아니라 '다음엔 저 선을 먼저 빼자'는 생각으로 바뀌었기 때문이다."

조건: 이 판단은 Claude의 Mac 플레이에 한정된 가정입니다. 사람의 손가락 터치·핀치, 소리, 광고, 10~20의 장시간 피로도는 확인하지 않았습니다.

### 새롭게 발견된 문제

이번 플레이 중 발견해 **고친 것** (자동 테스트 통과):

1. 이야기 카드가 떠 있는 동안 "막혔나요? 힌트" 말풍선이 뜨고 플레이 시계가 돌았습니다. 이제 이야기 카드 중에는 둘 다 멈춥니다(감사의 METRIC-01).
2. 판을 오래 만지지 않아도(화면 잠금 포함) 플레이 시계가 돌았습니다. 이제 90초 동안 터치가 없으면 시계가 멈춥니다.
3. 카메라 버튼은 1.6×, 자동 다가가기는 1.44×로 배율이 달랐습니다. 이제 같은 플레이 배율입니다.
4. 체크포인트 버튼 라벨이 "…남…"으로 잘렸습니다. 남은 개수를 아래 줄로 옮겼습니다.
5. 홈에서 "재도전"으로 다시 연 실패 카드가 길게 늘어났습니다. 다음 프레임에 크기를 다시 잽니다.
6. 칸 18~22px 화면에서는 선을 정확히 눌러도 바로 판정되지 않았습니다. "정확히 누름" 기준을 22px에서 18px로 낮췄습니다.
7. 이미 읽기 좋은 판(6, 전체 보기 칸 24px)도 확대로 다가가 그림을 잘랐습니다. 이제 칸 23px 이상이면 전체 보기로 둡니다.

**남은 문제:**

- **전체 보기 칸 14~17px(4, 7, 10, 12~15, 17~19):** 전체 보기에서 누르면 "애매함" 판정이 잦습니다. 확대해서 누르도록 안내 문구가 한 번 나오지만, 들썩임을 놓치면 다음 탭에서 하트를 잃을 수 있습니다.
- **20스테이지:** 전체 보기에서 머리를 읽을 수 없고(13px), 이동량이 많습니다. 사람 테스트 뒤 크기를 줄일지 정해야 합니다.
- **3·5처럼 폭 20칸인 판:** 다가가기 배율(약 1.4×)에서 좌우 2~3칸이 잘립니다. 첫 HARD는 요청대로 다가가게 뒀지만, 3(연습)은 전체 보기로 두는 편이 나을 수 있습니다.
- **16(쉬어가기):** 같은 모양 화살표 반복이 큽니다(가장 흔한 모양 16번, 다양성 0.41). 다음 레벨 작업에서 손볼 후보입니다.
- **4스테이지:** 28×28 별에 화살표 39개라 칸이 작고(16px) 성깁니다. 입문 판으로는 확대·이동 부담이 큽니다(이번 범위에서는 수정하지 않음).
- **실수 원인 구분:** 레이 판독 실수와 애매한 판정 후 이어진 탭을 로그에서 구분하기 어렵습니다(`touch_misses`만 셈).

### Android 및 광고 검증 상태

- **Android:** 이번 라운드 빌드로 디버그 APK를 만들었습니다(`build/outtap-debug.apk`). **실기기 설치·터치·핀치·성능은 아직 확인하지 않았습니다.** 기기 설치와 자동 조작은 사용자 확인 뒤에 하기로 되어 있습니다.
- **광고:**
  - Mac에서는 광고 공급자가 지원되지 않아(`UNSUPPORTED_PLATFORM`) 실제 노출 0회입니다.
  - 실패 후 전면 광고를 부르지 않는 것은 흐름 테스트(`last_skip` 미기록)와 GUI 플레이로 확인했습니다.
  - Android 테스트 광고의 실제 노출·복귀·보상 지급은 미검증입니다.
  - 운영 광고 ID 4개는 여전히 비어 있습니다(출시 차단 항목).
- **소리:** 청취하지 않았습니다. 음질·믹싱을 평가하지 않습니다.
