## 4. 실행하지 않은 것

- **기기:** 새 APK의 설치와 실기기 플레이·터치·성능 확인. 사용자 승인이 필요해서 하지 않았습니다.
- **사람의 판단:** 난이도·재미·HARD 공정함의 체감, 실제 풀이 시간.
- **청취:** 소리·음성의 실제 청취 검수.
- **광고:** 이번 빌드의 실제 테스트 광고 표시(이전 빌드에서는 확인).
- **외부 분석:** 외부 분석 전송(연결 없음).
- **배포:** 스토어 업로드·배포·원격 저장소 푸시(요청상 금지).
