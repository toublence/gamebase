## 2. 레벨 검증

- **빌드:** `BUILD_OK 20 levels`. 구조·풀이·풀이 재생·실루엣 중복 금지를 매번 확인합니다.
- **HARD 4판(5·10·15·20):** 처음 풀린 화살표 각 5개(기준 ≤6), 풀이 20~24층, 화살표 41~53개.
- **실루엣:** 18종이 서로 다르고, 1·2스테이지는 사각 판입니다.
- **렌더링 검토:** 각 스테이지 후보를 `tools/preview_arrows.py`로 렌더링해 1순위를 눈으로 확인한 뒤 고정했습니다. 4스테이지는 돛단배 실루엣이 작은 크기에서 텐트처럼 보여 별로 바꿨습니다.

## 3. 화면 캡처 검토 (데스크톱 실제 렌더러, 540×1170 창)

`tests/capture/capture_screens.tscn`이 검증용 별도 저장소에서 화면 19장을 캡처했습니다. 대표 화면은 `docs/screens/`에 있습니다.

**캡처로 찾아 고친 문제:**
1. 게임 HUD의 "스테이지 N" 제목이 사라짐. 말줄임 설정 때문에 가로줄 안에서 폭이 0이 됐습니다.
2. HARD 배너가 한 글자씩 세로로 쪼개짐. 최소 폭을 주고 번역문에 줄바꿈을 넣었습니다.
3. 클리어 카드의 시간·실수 표시와 리그 이름이 세로로 쪼개짐(자동 줄바꿈 해제).
4. 꾸미기 창 카드가 지정 높이보다 작게 나옴. 버튼 공통 코드가 최소 높이를 64로 덮어쓰던 기존 버그였습니다. 이제 큰 값은 유지되고, 홈의 큰 시작 버튼도 의도한 78 높이가 됩니다.
5. **설정 토글이 저장값과 관계없이 항상 "끔"으로 보이던 기존 버그.** 토글 모드가 켜지기 전에 상태를 넣어서 값이 무시되고 있었습니다. 실기기에서도 같은 문제가 있었을 것으로 보이며, 수정했습니다.
6. 꾸미기 창 견본 판의 화살표 칸 겹침(디버그 assert).
7. 밤 장면에서 주황 화살표와 황금 화살표가 헷갈릴 수 있음. 황금 화살표에 상시 금빛 후광을 넣었습니다.
8. 힌트 후광이 밤 장면에서 약함. 더 진하고 넓게 바꿨습니다.
9. 후반부 밤 장면 과다. 비 HARD 두 판을 낮 장면으로 돌렸습니다.

## 4. 오디오 객관 측정 (`tools/analyze_audio.py`)

- 효과음 19개 모두 클리핑 0, 최대 레벨 −1.0dBFS 이하입니다.
- 겹친 순간의 최대치(리미터 이전)는 빠른 연속 탈출 −6.5, 충돌+하트 −10.6, HARD 클리어 겹침 −7.8dBFS입니다.
- 배경음 루프 이음새: 일반은 평균 변화 수준, HARD는 같은 곡의 다른 마디 시작점 범위 안입니다. 자세한 값은 [AUDIO.md](AUDIO.md)에 있습니다.
- **음성:** 후보 420개 중 379개가 음성인식에서 의도한 단어로 인식됐습니다. 최종 14개는 14/14 재확인했습니다.

## 6. 기기

**이번 라운드의 새 APK는 기기에 설치하지 않았습니다.** 사용자 요청에 따라 폰 설치와 자동 조작은 승인을 받은 뒤 진행합니다.

준비된 도구는 `tools/device_play.py`입니다. 디버그 로그의 판 위치와 버튼 좌표를 읽어 실제 터치(adb)로 스테이지를 풀고, 스크린샷과 화면 녹화를 남깁니다.
